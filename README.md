# CHERNOBYL — 事故原因技术复盘

一条 **45.000 秒**的代码生成科普动画：24 场、一场一小节，用**数据图版**的语言讲
RBMK-1000 这起事故的物理与设计原因。

| | |
|---|---|
| 交付 | `out/chernobyl-45s.mp4` · 1920×1080 · 30 fps · **1350 帧 / 45.000 s 整** |
| 音乐 | 128 BPM，24 小节 × 1.875 s（画面与音乐共用同一张时间表，剪辑点全落在强拍上） |
| 风格牌 | `data-infographic` 数据图版 —— 图表是主角，按拍生长；一个数据点被唯一强调色高亮 |
| 渲染 | 纯 Python + numpy + PIL 光栅化，ffmpeg `h264_nvenc` 编码（不可用时回退 libx264）；无外部美术素材、无 AE、无 TTS |

## 本次交付实测

```
codec h264 · 1920x1080 · 30/1 fps · nb_frames 1350 · duration 45.000000 s
audio aac 384k 48 kHz stereo
Input Integrated −10.4 LUFS   （规范 −9 ~ −13）
Input True Peak  −0.9 dBTP    （规范 −1.0 ~ −0.5）
```

编码走的是 **libx264 CRF 16 兜底**：本机 ffmpeg 带着 `h264_nvenc`，但这个会话里
加载不了 `nvcuda.dll`（`Cannot load nvcuda.dll`，提权后同样如此），所以走回了 x264。
代价只是体积（1080p 带颗粒的素材 45 秒约 300 MB）与编码耗时，画面与声音不受影响。
`out/frames/` 里留着 1350 张 PNG 母版（3.3 GB），愿意的话可以随时换编码参数重出，
不必重渲；不需要就整目录删掉。

## 哪些是「示意」，以及为什么必须标出来

风格牌的注意事项是「编造的数字会变成虚假宣传」。这支片子只有三类东西不是实测值，
而且每一类都在画面上标了 `示意 · SCHEMATIC` 或 `（示意）`：

1. **图解的几何**：压力管、控制棒、厂房剖面都是示意图，不是按比例绘制的（标注写明
   「形状示意，刻度为真实值」）。
2. **中子收支的两根堆叠柱**（第 04 场）：只有量级方向是真的，纵向合计归一化到 100，
   没有可引用的分解实测值。
3. **几条曲线的形状**：压水堆的空泡系数参照线、石墨端头注入的反应性峰值、功率管
   沿轴向的空泡份额分布、氙毒的二室模型、石墨火的释放率曲线 —— 形状是示意，
   但落在曲线上的**刻度与端点值**是上表里的真实值。氙毒那条用的是真实半衰期算的
   二室模型（未计入剩余中子通量的燃耗）。

## 重渲

```powershell
cd <项目目录>
$env:PYTHONUTF8=1
py -3 -m chernobyl.build --stills 12     # 一场抽 7 帧看时间轴
py -3 -m chernobyl.build --at 13:1.20    # 某一拍的单帧全分辨率
py -3 -m chernobyl.build --jobs 6        # 全片
py -3 verify.py                          # 规格 / 帧数 / 响度 / 真峰自检
```

改数据只改 `chernobyl/theme.py`；改画面只改 `chernobyl/scenes.py`。

## 引擎侧的两处改动（相对模板）

1. **中文字面**：内置的 Archivo / Inter / JetBrains Mono **都不含 CJK**，直接拿来排中文
   会渲成豆腐块。工程里补了 Noto Sans SC 的 Regular / Medium / Bold 三个静态实例，
   `charts.tf(s, size)` 按内容挑字体：含中文走 Noto，纯数字/拉丁读数走等宽 ——
   这样「等宽数字 + 中性无衬线标签」的牌面语气还在，中文也不会掉字。
2. **并行方式**：Windows 沙箱不允许开**命名管道**（`\\.\pipe\...`），
   `multiprocessing.Pool` 一建 `SimpleQueue` 就 `PermissionError: [WinError 5]`。
   改成把场景切片交给若干独立子进程，各自写自己的帧文件、进程间零通信、
   stdout 落到 `out/worker_*.log`（不走任何管道）。一场景一进程，默认取逻辑核数的三分之一。

另外 `--jobs` 上限被 `min(len(idx), want)` 夹住 —— 一场景一核，多给没有意义。
